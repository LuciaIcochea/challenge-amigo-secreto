<h3>Descripción-del-proyecto</h3>
<p>Proyecto desarrollado como un reto dentro del programa Oracle One - Grupo 08, es un juego donde se pueden introducir nombres ilimitados para luego sortear aleatoriamente un nombre ganador. En el proyecto se aplican conocimientos básicos de Java Script</p>

<h3>Estado-del-proyecto</h3>
<P>:white_check_mark: PROYECTO CONCLUIDO :white_check_mark:</P>

<h3>Características-de-la-aplicación-y-demostración</h3>
<h4>Añadir lista de nombres</h4>
<p>Para añadir nombres a la lista a sortear, hay que colocar el pulsor en la casilla blanca, escribir los nombres y hacer click en el boton añadir, como se muestran en las siguientes imágenes:</p>

<h4>Sortear nombres</h4>

<p>Para sortear los nombres ingresados en la lista hacemos click en el botón "Sortear amigo". Se mostrará un texto EL AMIGO SECRETO ES: NOMBRE DEL AMIGO ELEGIDO. En el ejemplo Raul.</p>
